## What is it ?

This a bilibili regex script what i build for my <a href="https://github.com/zaynkhan100110/ump">ump</a> project

## What the work of it ?

While downloading a bilibili content you will encounter bunch of issues and i also encounter those. This automated script may helps you to deal with those issues.

## How does it work (How can this script talks to the server) ?

This automated scripts use playwright (a browserlike application and send requests to the bilibili server to get the content)

## Notice :::

Bilibili may update their regex again so keep updating this script. Also private video may not be foundable with this script
